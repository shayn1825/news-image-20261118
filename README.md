A deterministic, standard-library-only Python program that draws a newspaper front page summing up the world news of Wednesday 18 November 2026 — US strikes in the Gulf and Iran's response, the Kerch Bridge attack, the Xi–Putin meeting in Shenzhen, Mary Peltola's Alaska Senate win, Anthropic's IPO pricing, the US losing measles-free status, the DR Congo Ebola outbreak, and Voyager 1 reaching one light-day — as a single 1024×1024 PNG. It writes the image with its own embedded 5×7 bitmap font and a hand-written PNG encoder, so two runs produce identical bytes with no network access.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
